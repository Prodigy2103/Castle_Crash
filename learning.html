3. Wichtigste Lernpunkte & offene Review-Checkpoints

  • Zustands-Reset beim Ausweichen: this.isAttacking = isWallBroken && this.isColliding(character) sorgt dafür, dass Gegner weiterlaufen, wenn die Katze ausweicht.
  • undefined in Vergleichen: Ein fehlender Property-Name (lastAttack statt lastAttackTime) erzeugt NaN im Vergleich und unterdrückt Schaden lautlos.
  • Grafik vs. Canvas-Patch: Ein rechteckiges drawImage-Patch fällt auf Verläufen/überlappenden Objekten auf – daher wird als sauberer Ersatz später über photopea.com ein echtes Area1_broken.png erstellt.

2. Alle Klassen & Funktionen im Detail

initGame() js/game.js
import: Level, World

Funktion

  • initGame(): Holt #canvas aus dem DOM, prüft HTMLCanvasElement, erstellt new Level(Level.createBackgrounds()) und startet new World(canvas, level).
  • Wird über window.addEventListener("DOMContentLoaded", initGame) ausgelöst.
DrawableObject models/drawable_object.class.js
Basisklasse

Properties

  • img, x = 0, y = 0, width = 100, height = 100, imageCache = {}, currentImage = 0

Methoden

  • loadImage(imagePath): Lädt ein einzelnes Image direkt in this.img.
  • loadImages(imagePaths): Lädt ein Array von Pfaden vorab in this.imageCache[imagePath].
  • draw(context): Prüft this.img && this.img.complete und zeichnet via context.drawImage(...).
MoveableObject models/moveable_object.class.js
extends DrawableObject

Methoden

  • playAnimation(images): Berechnet currentImage % images.length, setzt this.img aus this.imageCache und erhöht currentImage.
Background models/background.class.js
extends MoveableObject

Properties & Konstruktor

  • width = 1280, height = 640
  • constructor(imagePath, offsetX): Ruft super() und this.loadImage(imagePath) auf, setzt this.x = offsetX und this.y = 640 - this.height.

  • static createBackgrounds(): Erzeugt 6 Background-Instanzen im Abstand 1279 px aus ImgHelper.background.areas.
Character models/character.class.js
extends MoveableObject import: ImgHelper, IntervalHub

Properties & Methoden

  • width = 120, height = 120, x, y, characterKey
  • constructor(characterKey = "c1", offsetX = 120, offsetY = 260): Lädt Startbild + alle Idle-Frames über loadImage / loadImages und startet animate().
  • animate(): Registriert einen 50-ms-Loop über IntervalHub.startInterval für this.playAnimation(idleFrames).
World models/world.class.js
import: Character

Properties & Methoden

  • characters (Array mit c1, c2, c3), canvas, context, level
  • constructor(canvas, level): Holt 2D-Kontext und startet this.draw().
  • draw(): Leert Canvas, zeichnet erst level.backgroundObjects, dann characters und plant nächsten Frame per requestAnimationFrame.
  • addObjectsToMap(objects): Ruft für jedes Element drawableObject.draw(this.context) auf.
  • addToMap(drawableObject): Zeichnet ein einzelnes Objekt (aktuell ungenutzt, vorbereitet für Spiegeln).
IntervalHub js/intervalhub.class.js
Statischer Timer-Hub

Properties & Methoden

  • static allIntervals = []: Speichert alle aktiven Interval-IDs.
  • static startInterval(func, timer): Startet setInterval und merkt sich die ID.
  • static stopInterval(intervalId): Stoppt ein einzelnes Intervall und entfernt es aus allIntervals.
  • static stopAllIntervals(): Stoppt alle registrierten Intervalle auf einmal.
ImgHelper js/imghelper.js
Asset-Registry (2.770 PNGs)

Interne Helper-Funktionen

  • buildFrames(prefix, frameCount): Generiert nummerierte Frame-Pfade (_00.png …).
  • buildCharacterMap(): Baut c1–c15 (idle, shoot).
  • buildRegularEnemyMap(): Baut reg1–reg8 (attack, dead, idle, walk).
  • buildBossEnemyMap(): Baut boss1–boss7 anhand von BOSS_FRAME_COUNTS.
  • buildUiMap(): Mapped alle 104 Ui/*.png auf saubere Keys.

Statische Kategorien
